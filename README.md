# Лаборатория нечётких величин Рэлея

Локальное приложение на Python. Каждый объект представляет отдельную функцию принадлежности с параметром σ. Программа выполняет арифметику через α-срезы, генерирует 100–300 величин и проводит иерархическую кластеризацию. Интерфейс и руководство — на русском языке.

Оформление версии 1.5 — «Строгая утилита»: навигация слева, результаты в центре и параметры справа. На экранах уже 1200 px параметры переносятся над результатами, на телефоне навигация сворачивается. Подробные пояснения доступны в раскрывающихся блоках. Цвета в основном обозначают объекты на графиках; сами поля, кнопки и таблицы оформлены нейтрально.

## Математическая модель

Исходная плотность Рэлея нормируется по максимуму: μσ(x) = (x/σ) exp((1 − x²/σ²)/2) для x > 0, иначе 0. Максимум равен 1 при x = σ. Степень принадлежности не является вероятностью, площадь под μ не фиксируется.

Для вычислений используются 401 равномерный α-уровень от ε = 0,001 до 1. Исходная кривая имеет бесконечный хвост. Арифметика, расстояние и ранг работают с конечным приближением, отсекающим принадлежности ниже ε. Границы исходных срезов находятся методом Брента; границы результатов между узлами линейно интерполируются. Максимум среза при α = 1 обрабатывается точно.

Операнды интерпретируются как независимые нечёткие величины. В частности, A − A в общем случае не сводится к точному нулю. Результаты операций хранятся как α-срезы без подгонки к кривой Рэлея. Деление не определено, когда срез знаменателя содержит ноль. Ограничение проверяется на всём рабочем диапазоне уровней.

Ранг — интеграл центров срезов, делённый на 1 − ε. Совпадение рангов означает равенство по этому способу сравнения, но не равенство форм. Расстояние — корень из интеграла суммы квадратов различий границ, делённого на 2(1 − ε). Интегралы приближены методом трапеций.

Кластеризация использует complete linkage. Точный K получается после N − K объединений дерева, включая случаи равных расстояний. Порог T ограничивает высоту объединений. Кластеры упорядочены по среднему рангу, чтобы цвета были последовательными. При K, большем числа различных объектов, совпадающие величины могут оказаться в разных кластерах: это следствие требования ровно K.

Режим **«Авто»** выбирает число групп по Gap statistic с правилом **global 1-SE**. Для K от 1 до min(10, N−1, числа различных σ) строятся разбиения полной связью. Внутригрупповая дисперсия W(K) сравнивается со средним log W(K) по 100 равномерным контрольным наборам σ в диапазоне исходных данных. Gap(K) = среднее log W_ref(K) − log W(K). Выбирается наименьшее K, для которого Gap(K) ≥ max Gap − s_best, где s = SD(log W_ref) × sqrt(1 + 1/100). Seed контрольных наборов всегда 42 и не зависит от seed генератора исходных величин.

Нормировка σ к [0; 1] сохраняет критерий: расстояния между исходными величинами Рэлея пропорциональны разности σ. W(K) равна сумме квадратов отклонений от средних внутри групп; это эквивалентно дисперсии по квадратам расстояний нечётких величин с общим множителем, который сокращается в Gap. Алгоритму не передаются режим генерации и исходные метки групп. Для всех одинаковых величин и наборов менее трёх объектов выбирается одна группа. Автоподбор может оставить одну группу и для других данных; это оценка относительно равномерной контрольной модели, а не доказательство отсутствия любой структуры. Число групп ограничено диапазоном поиска, параметры и диагностика сохраняются в JSON.

## Сценарии для проверки

Генерируются **параметры σ отдельных величин**, а каждая функция принадлежности по-прежнему имеет форму Рэлея. В новых смесях параметры σ разыгрываются около центров источников с нормальным разбросом и повторным розыгрышем неположительных значений.

| Сценарий | Что проверять |
|---|---|
| Три разделённые группы | Исходный контрольный пример |
| Один равномерный диапазон | Отсутствие специально заложенных сгущений |
| Случайная смесь | От 2 до 6 источников; другой seed меняет число, центры, ширину и размеры |
| Разные размеры и ширина | Четыре источника с неодинаковым числом объектов и разбросом |
| Перекрывающиеся группы | Три источника перемешаны; геометрических кластеров может быть меньше |
| Группы и выбросы | Три компактных источника и 8% внешних объектов |
| Конструктор смеси | 2–8 источников, разделённость, неравномерность размеров и 0–20% выбросов |

После анализа откройте **«Проверить по исходным группам»**: две согласованные диаграммы σ показывают источники и найденные кластеры полной связи, таблица показывает переход объектов между группами. ARI сравнивает разбиения независимо от нумерации: 1 означает совпадение, около 0 — согласие на уровне случайного, возможны отрицательные значения. Из ARI исключаются помеченные при генерации выбросы; в диаграмме и таблице они остаются. Полная связь распределяет все объекты, HDBSCAN может оставить шум.

Исходные метки — сведения о способе генерации, а не обещание, что их всегда можно восстановить по σ. При сильном перекрытии одинаковые параметры возникают из разных источников. Кластеризация получает только величины; метки подключаются после её завершения. Ручное изменение σ или добавление величины снимает исходные метки; JSON проверяет их соответствие набору по контрольной сумме значений.

При N = 150 и seed = 42 сценарий разных размеров даёт 4 найденные группы и ARI = 1; перекрытие — 1 группу; выбросы — 6 групп при 3 основных источниках. Это контрольные результаты для указанных настроек, а не гарантия для любых данных.

Для исходного однопараметрического семейства расстояние пропорционально |σA − σB|. Поэтому график объектов использует одну числовую ось σ; вертикальная ось обозначает категорию кластера.

## Сравнение с HDBSCAN

В разделе **«Кластеры»** по умолчанию включено **«Сравнить с HDBSCAN»**. Кнопка **«Рассчитать»** запускает текущий метод (полная связь с Gap, K или T) и HDBSCAN. Оба используют одинаковые расстояния по α-срезам. Источники генерации ни одному алгоритму не передаются.

HDBSCAN из scikit-learn получает готовую матрицу расстояний (`metric="precomputed"`). По расстояниям до соседей оценивается плотность, строится иерархия взаимной достижимости и выбираются устойчивые группы методом EOM. Число групп и фиксированный радиус не задаются. Начальные параметры: `min_cluster_size=10`, `min_samples=10` (включая сам объект), `allow_single_cluster=True`. Последний параметр разрешает одну группу, которая тоже может сопровождаться шумом. Эти настройки находятся в правой панели. Подробности доступны в блоке «О настройках».

Положительные номера групп упорядочены по среднему рангу. **0 означает шум и не входит в число кластеров**. На графике это серые крестики. Таблица показывает число кластеров, шум и долю распределённых объектов. В блоке «Состав и кривые» можно выбрать метод и группу; шум доступен отдельно. Дендрограмма всегда относится к полной связи, а номера групп локальны для каждого метода.

При наличии источников ARI считается без заданных генератором выбросов. Отвергнутые обычные объекты учитываются с меткой 0. Смотрите на ARI вместе с долей распределённых объектов; при полном шуме ARI не выводится. На наборе с выбросами дополнительно показаны обнаруженные выбросы и обычные объекты, попавшие в шум.

При N = 150, seed = 42:

| Сценарий | Полная связь + Gap | HDBSCAN | Шум HDBSCAN |
|---|---:|---:|---:|
| Три разделённые группы | 3 | 3 | 0 |
| Разные размеры и ширина | 4 | 4 | 0 |
| Перекрывающиеся группы | 1 | 1 | 40 |
| Группы и выбросы | 6 | 3 | 8 |

В последнем случае 8 из 12 заданных выбросов выделены как шум, остальные присоединены к группам. Это проверенные результаты конкретных настроек, а не гарантия обнаружения всех выбросов. На равномерном наборе HDBSCAN может выделить случайные сгущения или оставить часть объектов шумом. Если N меньше любого из двух минимумов, весь набор считается шумом. Полностью совпадающие объекты дают одну группу, если она разрешена; иначе весь набор становится шумом.

## Отбор внутри кластеров по α

После «Рассчитать» общий для двух методов **порог соответствия кластеру α** равен 0. Перетащите ползунок или введите число от 0 до 1, например `0,43`, и нажмите Enter. Диаграммы, счётчики и открытые кривые обновляются во время движения. Цветные точки прошли порог, серые пустые кружки остались ниже него на строках своих групп. Серые крестики — исходный шум HDBSCAN. Справа от группы видно, сколько объектов осталось из исходного числа.

Центр группы C — средние левые и правые границы её срезов. Для исходных величин Рэлея σ центра равен среднему σ группы. Пусть dᵢ = D(Aᵢ, C) — расстояние от объекта до центра, а s² — среднее dᵢ² по исходной группе. Тогда оценка uᵢ = exp(−dᵢ² / (2s²)). Остаются объекты с uᵢ ≥ α. При нулевом разбросе все оценки равны 1. При α = 1 группа может опустеть, если ни один объект не совпадает с центром.

Для одной группы с σ = 1, 2, 3 оценки примерно равны 0,472367; 1; 0,472367. При α = 0,5 остаётся только σ = 2. На наборе «Группы и выбросы» с N = 150 и seed = 42 при α = 0,43 остаются 118 из 150 объектов полной связи и 119 из 142 в группах HDBSCAN; восемь объектов исходного шума учитываются отдельно.

Оценка показывает типичность внутри своей группы и зависит от её разброса. Это не вероятность. Центры, номера групп, Gap, дендрограмма и ARI относятся к исходному разбиению. Порог не связан с α-срезом кривой Рэлея. Новый расчёт или изменение набора сбрасывает порог; импорт JSON его восстанавливает.

```python
print(clusters.labels)
```

Для нового сценария используйте `generate_scenario(scenario="unequal")`: результат содержит `items` и отдельный `provenance`. Передавайте в `cluster_auto` только `items`. Команда `python -m examples.try_scenarios` проверяет все сценарии без интерфейса.

```python
from fuzzy_clustering import cluster_hdbscan
density = cluster_hdbscan(items, min_cluster_size=10, min_samples=10,
                          allow_single_cluster=True)
print(density.k)       # число групп без шума
print(density.labels)  # 0 = шум, 1..K = группы
```

`python -m examples.compare_methods` сравнивает оба метода на наборе с выбросами и сохраняет JSON и CSV в текущую папку. Пример готового сравнения: `examples/comparison-session.json`.

## Файлы и ограничения

JSON версии 1 содержит `config`, исходные `items`, сохранённые `results`, настройки и метки последней кластеризации, общие параметры интерфейса. Необязательное поле `generation` хранит сценарий, параметры, seed, описания источников, метки объектов и контрольную сумму. Для «Авто» сохраняются выбранное K, критерий, правило выбора, предел поиска, количество и seed контрольных наборов, значения Gap и погрешности. При загрузке кластеризация пересчитывается по сохранённым настройкам. Старые сессии без сведений о генерации поддерживаются. Набор может содержать 1–300 объектов после импорта или ручного добавления; генератор создаёт 100–300. Можно сохранить до 100 результатов операций.

Необязательное поле JSON `comparison` хранит параметры и метки HDBSCAN. При загрузке оба анализа пересчитываются по сохранённым настройкам. Старые сессии без сравнения поддерживаются. Порог хранится в `controls.cluster_alpha`; оценки — в блоках `membership` обоих результатов с правилом `gaussian_rms_v1`. Для исходного шума оценка равна `null`. Если порог отсутствует, используется 0.

CSV имеет столбцы `id,sigma,cluster`; `cluster` относится к полной связи. После сравнения добавляются `hdbscan_cluster,hdbscan_noise`: номер 0 и флаг 1 обозначают шум. После анализа в приложении добавляются столбцы `cluster_score`, `cluster_retained`, `cluster_alpha` и при сравнении соответствующие столбцы с префиксом `hdbscan_`. У шума оценка пуста. CSV сохраняет все исходные строки и метки, включая объекты ниже порога. До выполнения анализа поле кластера пустое. Импорт выполняется через JSON; CSV предназначен для просмотра таблиц в сторонних программах. Невалидный JSON, повторяющиеся идентификаторы и неположительные σ отклоняются. Размер загружаемого файла ограничен 10 МБ.

Данные текущей браузерной сессии сохраняются при навигации. Перед закрытием или перезапуском скачайте JSON, чтобы восстановить эксперимент. Папка `runtime` содержит только настройки запуска и технический вывод сервера для диагностики. Она не входит в архив проекта, как и установленное окружение `.venv`.

Исходные σ в интерфейсе вводятся от 0,000001 до 1000000. Библиотеки допускают конечные положительные σ; переполнение результата арифметики обрабатывается ошибкой. Рабочий порог и сетка сохраняются в сессии. Генератор по умолчанию использует три диапазона [0,6; 1,2], [2,4; 3,0], [4,8; 5,4] без передачи исходных меток алгоритму.
